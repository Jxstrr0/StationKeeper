# Module models

One `.glb` per module, generated by `tools/blender/build_models.py` (see `tools/blender/README.md`) and committed as
normal files, not Git LFS, so GitHub Pages serves them as they are. A module uses one through
`"model": "models/<id>.glb"` in `src/data/modules.json`. If the file is missing or fails to load, the module is drawn
as its grey-box instead.

A model holds geometry only: no textures, no lights, no cameras. The view supplies the materials.

## Conventions the view looks for

- **Frame.** The model's origin is the module's origin, in metres, +Y up; port positions in `modules.json` are in the
  same frame. Node transforms are identity apart from the ones named below.
- **Materials by name.** Each material in the file is replaced by the shared one of the same name from
  `src/view/stationMaterials.ts`: `hull`, `white`, `slate`, `dark`, `stripe`, `rail`, `foil`, `quilt`, `panel`,
  `radiator`, `window`. Colours in the file are ignored. A material with any other name is kept as the file has it.
- **One primitive per material.** The node `body` is a single mesh with one primitive per material, so a module costs
  about as many draw calls as it has materials.
- **Vertex colours.** `COLOR_0` carries baked ambient occlusion (grey, multiplied into the surface colour).
- **UVs** are present only on the textured materials (`hull`, `quilt`, `foil`, `panel`, `radiator`) and are in tiling
  space: one unit is one repeat of that material's texture, which covers 4, 3, 2, 1.6 and 2 m respectively.
- **`status_light`**: an empty node. The status light is put there and recoloured by power status. If it is missing,
  the light goes at `greybox.light`.
- **`gimbal`** (solar arrays): an empty node at the pivot, with the tracking part as its child. It is rotated about the
  module's `gimbalAxis` to follow the sun.
- **`glow`**: a mesh in the `window` material for panes that are lit whenever the module is powered.
- **`win_<ring>_<slot>`**: one node per pane that lights by how many guests are aboard (habitat and lounge). All panes
  of a ring share one mesh and are drawn as a single instanced mesh; `slot` is the pane's place round the hull, and the
  view lights them in a scattered order.
- **Compression.** Normals and colours are quantised (`KHR_mesh_quantization`); there is no Draco or meshopt, so the
  loader needs no decoder.
- **Size.** Stay inside `greybox.size`, with docking ports at most 0.17 m proud. The build menu tests fit by the bounds
  of the model's meshes.

Budget: about 8,000 triangles for a typical module, 15,000 at most.
