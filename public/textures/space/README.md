# Space textures

All from NASA, all public domain, resized and cleaned up for the game:

- `earth-day-*.jpg`: Blue Marble Next Generation with topography and bathymetry, December (NASA Earth Observatory).
- `earth-night-*.jpg`: Black Marble 2016 (NASA Earth Observatory), with the moonlit land taken out so only the lights remain.
- `milky-way-1k.jpg`: Deep Star Maps 2020, the Milky Way layer (NASA Scientific Visualization Studio), blurred to a glow.
- `moon-512.jpg`: CGI Moon Kit colour map (NASA Scientific Visualization Studio, from Lunar Reconnaissance Orbiter data).

The view loads the 2k maps first and swaps in the 4k ones unless graphics are set to Low.
