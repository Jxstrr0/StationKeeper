# Station art from Blender

Everything under `public/models/` and `public/textures/station/` is generated by the Python here. The outputs are
committed, so neither CI nor a normal `npm run build` needs Blender. Rerun only when you change the art.

## Setup

The scripts use Blender as a Python module (`bpy`), plus numpy and Pillow. Written and tested with `bpy` 5.2.

```sh
python3 -m venv ~/.venvs/bpy            # the Python version must match the bpy wheel (3.13 for bpy 5.2)
~/.venvs/bpy/bin/pip install bpy numpy pillow
```

## Models

```sh
~/.venvs/bpy/bin/python tools/blender/build_models.py                    # all twelve
~/.venvs/bpy/bin/python tools/blender/build_models.py core habitat       # just these
~/.venvs/bpy/bin/python tools/blender/build_models.py --preview /tmp/pv  # also render a preview PNG of each
```

For each module in `src/data/modules.json` this builds the mesh, bakes ambient occlusion into vertex colours with
Cycles, exports `public/models/<id>.glb` and repacks it (quantised normals and colours, 16-bit indices). It prints the
triangle count and file size of each. Sizes and port positions come from `modules.json` (`greybox.size`, `ports`), so a
module resized there is rebuilt to match.

- `sk/geo.py` builds meshes: lathes, tubes, boxes, struts, panels, each with a material and metre-scaled UVs.
- `sk/fittings.py` holds the shared parts: docking ports, pressure cans, handrails, trusses, dishes.
- `sk/modules.py` has one builder per `greybox.shape`. This is the file to edit to change how a module looks.
- `sk/scene.py` holds the materials, the AO bake and the export. `sk/glb.py` is the repack.

Nothing is random: the same script and Blender version give the same geometry. The baked AO is quantised to 32
levels, which keeps reruns close to byte-identical, but expect small diffs in the `.glb` files after a rebuild.

Keep a module inside its grey-box size (`greybox.size`), apart from docking ports, which may stand 0.17 m proud. The
build menu tests whether a module fits by the bounds of its meshes, so a part sticking out further can block a
neighbouring port that the grey-box left free.

## Textures

```sh
~/.venvs/bpy/bin/python tools/blender/bake_textures.py           # all five sets
~/.venvs/bpy/bin/python tools/blender/bake_textures.py foil
```

Bakes five tiling 512 px sets (`hull`, `quilt`, `foil`, `panel`, `radiator`), each as `<name>_albedo.jpg`,
`<name>_normal.jpg` and `<name>_rough.jpg`. Each surface is a procedural node graph baked on a plane as a few masks,
which are then composed into the three maps. The normal map is derived from the baked height with wrap-around, so it
tiles. One repeat covers `TILE[name]` metres (`sk/geo.py`); `src/view/stationMaterials.ts` relies on the models' UVs
being in those units.

What the game expects inside a model is written down in `public/models/README.md`.
